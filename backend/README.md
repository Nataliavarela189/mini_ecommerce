# 🛍️ Mini Ecommerce - Backend

Sistema de gestión de productos, clientes y pedidos, desarrollado en **Node.js + Express + Sequelize + SQLite**.

---

## 📋 Funcionalidades

- CRUD completo de **Productos**, **Clientes** y **Pedidos**  
- Relación entre tablas (**Cliente → Pedido → PedidoItem → Producto**)  
- Cálculo automático del total del pedido  
- Persistencia en base de datos **SQLite**  
- Operaciones transaccionales en el alta de pedidos con ítems  
- Restricciones de integridad referencial (foreign keys)  
- Manejo de errores  

---


## ⚙️ Tecnologías utilizadas

- **Node.js**
- **Express**
- **Sequelize ORM**
- **SQLite**
- **Nodemon** (para desarrollo)
