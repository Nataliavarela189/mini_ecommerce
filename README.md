# 🛒 Mini Ecommerce (Node.js + SQLite)

Aplicación web tipo ecommerce desarrollada con backend en Node.js y frontend en HTML/JavaScript. Permite gestionar productos y simular operaciones básicas de compra.

---

## 🧩 Descripción

Este proyecto implementa un sistema simple de ecommerce con:

* Backend en **Node.js**
* Base de datos **SQLite**
* ORM **Sequelize**
* Frontend en **HTML + JavaScript (vanilla)**

Está orientado a practicar desarrollo fullstack con foco en APIs y persistencia de datos.

---

## 🚀 Funcionalidades

* Listado de productos
* Alta, edición y eliminación de productos (CRUD)
* Persistencia en base de datos SQLite
* Consumo de API desde el frontend
* Simulación de flujo de compra

---

## 🏗️ Arquitectura

* API REST desarrollada en Node.js
* Separación básica entre rutas, modelos y lógica
* Uso de **Sequelize** como ORM para interactuar con la base de datos

---

## ▶️ Ejecución del proyecto

### 1. Clonar repositorio

```bash id="1h0bsp"
git clone https://github.com/tuusuario/mini-ecommerce.git
cd mini-ecommerce
```

### 2. Instalar dependencias

```bash id="z3e8vt"
npm install
```

### 3. Ejecutar servidor

```bash id="yy8b6q"
node app.js
```

### 4. Abrir en navegador

Abrir el archivo HTML del frontend o acceder a:

```id="h0r5wq"
http://localhost:3000
```
